# PkgDependsGraf — Инструмент визуализации графа зависимостей

CLI-приложение для анализа зависимостей пакетов и их графической визуализации. 
Проект разрабатывается поэтапно в рамках практического задания.

## 📝 Общее описание

Программа читает конфигурационный файл, получает данные о зависимостях выбранного пакета из экосистемы npm, строит граф зависимостей с учетом транзитивности и визуализирует его. 

Текущее состояние репозитория: **Этап 3 завершен**. Программа умеет строить полный граф зависимостей (с обходом в ширину), обрабатывать циклы, фильтровать пакеты и поддерживает тестовый режим.

### 🛠️ Стек технологий
*   **Free Pascal (FPC)** — основной язык программирования.
*   **`Generics.Collections`** — для хранения графа (используется `TDictionary`).
*   **`fphttpclient`, `opensslsockets`** — для выполнения HTTP-запросов к API npm.
*   **`fpjson`, `jsonparser`** — для парсинга JSON-ответов.
*   **Bash + `yq`** — вспомогательный слой для чтения и валидации YAML-конфигурации.
*   **Make** — система сборки проекта.
*   **Graphviz** (план на Этап 5) — для генерации PNG-изображений графа.

## 📂 Структура проекта

| Файл | Назначение |
| :--- | :--- |
| `PkgDependsGraf.pas` | Главный файл программы (точка входа, вывод графа в консоль). |

| `config.yaml` | Пример конфигурационного файла. |
| `Makefile` | Автоматизация сборки и очистка артефактов. |

## ⚙️ Конфигурация

Программа управляется через YAML-файл. Имя файла передается первым аргументом при запуске.

### Параметры конфигурации (config.yaml)

```yaml
# Имя анализируемого пакета (например, express, axios)
package_name: express

# Для режима online: URL реестра. Для режима test: путь к файлу.
repo_url: https://registry.npmjs.org/

# Режим: online (реальный NPM) или test (локальный файл)
repo_mode: online

# Имя выходного PNG-файла (будет использоваться на Этапе 5)
output_file: graph.png

# Выводить ли ASCII-дерево (уже реализовано в консоли)
ascii_tree: true

# Игнорировать пакеты, в имени которых есть эта подстрока
filter_substring: test
