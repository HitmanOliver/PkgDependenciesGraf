# PkgDependsGraf — Инструмент визуализации графа зависимостей

CLI-приложение для анализа зависимостей пакетов и их графической визуализации. 
Проект разрабатывается поэтапно в рамках практического задания.

## 📝 Общее описание

Программа читает конфигурационный файл, получает данные о зависимостях выбранного пакета (на данном этапе — из экосистемы npm), строит граф зависимостей и визуализирует его. 

Текущее состояние репозитория: **Этап 1 завершен** (чтение и валидация конфигурации). Начата подготовка к Этапу 2.

### 🛠️ Стек технологий
*   **Free Pascal (FPC)** — основной язык программирования (ООП, работа с процессами).
*   **Bash** — вспомогательный слой для парсинга конфигурации.
*   **yq** — утилита командной строки для обработки YAML (используется через bash).
*   **Make** — система сборки проекта.
*   **Graphviz** (план на Этап 5) — для генерации PNG-изображений графа.

##  Структура проекта

| Файл | Назначение |
| :--- | :--- |
| `PkgDependsGraf.pas` | Главный файл программы (точка входа, обработка исключений). |

##  Конфигурация

Программа управляется через YAML-файл. Имя файла передается первым аргументом при запуске.

### Параметры конфигурации (config.yaml)

```yaml
# Имя анализируемого пакета
package_name: express

# URL-адрес репозитория (для online) или путь к файлу (для test)
repo_url: https://registry.npmjs.org

# Режим: online, offline или test
repo_mode: online

# Имя выходного PNG-файла
output_file: graph.png

# Выводить ли ASCII-дерево зависимостей
ascii_tree: true

# Подстрока для фильтрации пакетов (пустая строка = без фильтра)
filter_substring: test
