# PkgDependsGraf — Инструмент визуализации графа зависимостей

CLI-приложение для анализа зависимостей пакетов и их графической визуализации. 
Проект разрабатывается поэтапно в рамках практического задания.

##  Общее описание

Программа читает конфигурационный файл, получает данные о зависимостях выбранного пакета из экосистемы npm, строит граф зависимостей и визуализирует его. 

Текущее состояние репозитория: **Этап 2 завершен**. Программа умеет парсить YAML-конфиг и получать список прямых зависимостей пакета напрямую из реестра npm.

###  Стек технологий
*   **Free Pascal (FPC)** — основной язык программирования. 
*   **`fphttpclient`, `opensslsockets`** — для выполнения HTTP-запросов к API npm и поддержки HTTPS.
*   **`fpjson`, `jsonparser`** — для парсинга JSON-ответов от реестра npm.
*   **Bash + `yq`** — вспомогательный слой для чтения и валидации YAML-конфигурации (используется только для конфига, зависимости качаются нативно на Паскале).
*   **Make** — система сборки проекта.
*   **Graphviz** (план на Этап 5) — для генерации PNG-изображений графа.

##  Структура проекта

| Файл | Назначение |
| :--- | :--- |
| `PkgDependsGraf.pas` | Главный файл программы. Содержит логику HTTP-запросов, парсинга JSON, извлечения зависимостей и точку входа. |
| `ParseConfig.pp` | Модуль для чтения, валидации и парсинга YAML-конфига через вызов bash-скрипта. |
| `parseYAML.sh` | Bash-скрипт, вызывающий `yq` для извлечения данных из YAML. |
| `config.yaml` | Пример конфигурационного файла. |
| `Makefile` | Автоматизация сборки, отслеживание зависимостей и очистка. |

## Конфигурация

Программа управляется через YAML-файл. Имя файла передается первым аргументом при запуске.

### Параметры конфигурации (config.yaml)

```yaml
# Имя анализируемого пакета (например, express, axios, lodash)
package_name: express

# URL-адрес репозитория npm
repo_url: https://registry.npmjs.org/

# Режим: online, offline или test (в разработке)
repo_mode: online

# Имя выходного PNG-файла
output_file: graph.png

# Выводить ли ASCII-дерево зависимостей (в разработке)
ascii_tree: true

# Подстрока для фильтрации пакетов (в разработке)
filter_substring: test
